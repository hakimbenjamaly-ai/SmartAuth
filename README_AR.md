# منظومة التصديقات والأرشفة الذكية
**Smart Authentication & Certification Management System** — الإصدار 1.0.0

برنامج سطح مكتب لنظام Windows يعمل على جهاز واحد **دون إنترنت**، بواجهة عربية بالكامل (RTL)، وقاعدة بيانات محلية SQLite، لإدارة بيانات الأشخاص المخولين بالتوقيع والتصديق لدى السفارات والقنصليات والشركات والوزارات والهيئات والمؤسسات.

---

## 1. ما الذي تم تنفيذه

| المتطلب | التنفيذ |
|---|---|
| تسجيل الدخول (اسم، كلمة مرور، إظهار/إخفاء) | `app/ui/login.py` — تجزئة PBKDF2-SHA256، قفل الحساب 15 دقيقة بعد 5 محاولات خاطئة |
| حسابان: مشغل رئيسي / مستخدم عادي | واجهة مستقلة لكل نوع؛ المستخدم العادي لا تظهر له صفحات Excel أو الإدارة |
| التحقق من الصلاحيات داخل النظام وقاعدة البيانات | **طبقتان**: فحص في كل دالة خدمة (`@require`) + `sqlite3 authorizer` يمنع اتصال المستخدم العادي من أي INSERT/UPDATE/DELETE/DROP ويخفي عمود كلمات المرور |
| تصنيفات الجهات التسعة وقوائمها الفرعية | مخزنة في قاعدة البيانات (غير مثبتة في الكود)، قابلة للإضافة والتعديل والحذف، مع الدول والمدن |
| إدارة مصادر البيانات | عدد غير محدود من المسارات، ربط بالتصنيف، أنواع الملفات، المجلدات الفرعية اختيارياً، فحص المسار، بدء القراءة |
| منع الاستيراد المكرر | بصمة SHA-256 لكل ملف |
| قراءة PDF النصي | استخراج طبقة النص مباشرة |
| قراءة PDF الممسوح والصور (JPG/JPEG/PNG/TIFF متعدد الصفحات/BMP/WEBP) | تحسين الجودة (إزالة التشويش، توحيد الإضاءة، تصحيح الميل) ثم Tesseract عربي+إنجليزي |
| الكتابة اليدوية | الأسطر ضعيفة الثقة والمناطق غير المقروءة تُمرر لنموذج TrOCR محلي (انظر القسم 5) |
| تنبيه بالبيانات غير المقروءة | تحذيرات لكل صفحة بموضع المنطقة غير المقروءة، والحقول الأساسية التي لم تُستخرج |
| استخراج الحقول | الاسم (عربي/إنجليزي)، الصفة، الجهة، الدولة، التواريخ (ميلادية وأسماء الأشهر الليبية والعربية)، الهواتف (محلي/دولي/أرقام عربية)، البريد، تواريخ التفويض، الرقم الإشاري |
| مراجعة البيانات واعتمادها | تعديل كل حقل، اختيار صور التوقيع المقترحة تلقائياً من الصفحة، اعتماد ← إنشاء/تحديث الشخص والجهة والتفويض وسجل التصديق |
| أرشفة التوقيعات والأختام | تُنسخ إلى مجلدات منظمة، والمسار في قاعدة البيانات؛ الأصل للقراءة فقط ولا يعدل |
| البحث بالاسم/الجهة/الهاتف | تطبيع عربي (الهمزات، الياء، التاء المربوطة، التشكيل) وتطبيع الهاتف (+218 / 00218 / 09…) |
| وحدة البحث بالتوقيع عبر الماسح | كل الأزرار المطلوبة؛ WIA و TWAIN؛ معالجة الصورة وتحديد منطقة التوقيع؛ ترتيب النتائج بالنسبة؛ مقارنة جنباً إلى جنب؛ تضييق النطاق بالتصنيف/الدولة/الجهة؛ رسالة عدم العثور؛ صورة البحث مؤقتة ولا تسجل كتوقيع رسمي؛ تنبيه قانوني دائم |
| حالة التفويض وتواريخ صلاحيته | ساري / منتهي (تلقائياً عند تجاوز التاريخ) / موقوف / ملغى |
| السجلات التاريخية للتصديقات | لكل شخص، مرتبطة بالمستند المصدر |
| ملفات Excel | عرض، تعديل، تنقل بين الأوراق، إضافة ورقة/صف، حفظ مع نسخة تلقائية قبل الحفظ، واستيراد الأشخاص من ورقة بمطابقة الأعمدة |
| النسخ الاحتياطي والاستعادة | ملف ZIP واحد (قاعدة البيانات + الأرشيف)، فحص سلامة قبل الاستعادة، نسخة أمان تلقائية قبل الاستعادة |
| سجل العمليات | كل دخول وإضافة وتعديل وحذف واستيراد وبحث |
| ملف تثبيت | PyInstaller + Inno Setup، يضم Tesseract وملفات اللغة والنماذج؛ المستخدم النهائي لا يثبت شيئاً |

## 2. هيكل المشروع

```
smart_auth/
├── main.py                     نقطة التشغيل
├── app/
│   ├── core/                   الإعدادات، قاعدة البيانات، الأمان، الصلاحيات، تطبيع النصوص
│   ├── engine/                 OCR، معالجة الصور، استخراج الحقول، مطابقة التوقيعات، الماسح
│   ├── services/               منطق الأعمال (كل دالة تتحقق من الصلاحية)
│   └── ui/                     واجهة PySide6 (Qt) عربية RTL
├── tests/                      اختبارات آلية (16 اختباراً)
├── tools/download_models.py    تنزيل ملفات اللغة والنماذج مرة واحدة على جهاز البناء
└── installer/                  build.bat، ملف PyInstaller، سكربت Inno Setup
```

**مكان البيانات:** `C:\ProgramData\SmartAuth\` (قاعدة البيانات `database\`، الأرشيف `archive\signatures|stamps|documents`، `backups\`، `temp\`، `logs\`). يمكن تغييره بمتغير البيئة `SMART_AUTH_HOME`.

## 3. بناء ملف التثبيت

### الطريقة الأسهل: البناء التلقائي على GitHub (دون جهاز بناء)
1. أنشئ حساباً على github.com ثم مستودعاً جديداً **خاصاً (Private)**.
2. ارفع محتوى مجلد `smart_auth` كاملاً إلى المستودع (زر Add file ← Upload files)، مع التأكد من رفع المجلد `.github`.
3. افتح تبويب **Actions** ← **Build Windows Installer** ← **Run workflow**.
4. بعد انتهاء التشغيل (حوالي 15–30 دقيقة) افتح صفحة التشغيل ونزّل **SmartAuth_Setup** من قسم Artifacts.
   (يتوفر أيضاً **SmartAuth_Portable**: نسخة تعمل بفك الضغط دون تثبيت، و**selftest-log**: نتيجة الفحص الذاتي.)
5. انسخ ملف `SmartAuth_Setup_1.0.0.exe` إلى جهاز العمل وثبّته — لا يحتاج إنترنت بعد ذلك.

### الطريقة اليدوية: على جهاز Windows (مرة واحدة)

المتطلبات على جهاز البناء فقط (يحتاج إنترنت أثناء البناء فقط):
1. Windows 10/11 64-bit.
2. Python 3.11 أو أحدث (64-bit).
3. Tesseract 5 (نسخة UB Mannheim) مثبت في `C:\Program Files\Tesseract-OCR`.
4. Inno Setup 6.
5. (اختياري) ملف `Arabic.isl` بجانب `installer\SmartAuth.iss` لتعريب معالج التثبيت.

ثم:
```bat
cd smart_auth
installer\build.bat
```
لتضمين نموذج الكتابة اليدوية:
```bat
set WITH_HANDWRITING=1
set ARABIC_HTR_MODEL=<معرّف نموذج TrOCR عربي أو مسار مجلده>
installer\build.bat
```
الناتج: `dist_installer\SmartAuth_Setup_1.0.0.exe` — يُنسخ إلى الجهاز المستهدف ويُثبت دون إنترنت.

**عند أول تشغيل** تظهر شاشة لإنشاء حساب المشغل الرئيسي، ثم شاشة الدخول.

للتشغيل من المصدر أثناء التطوير: `run_dev.bat`. وللاختبارات: `python -m pytest -q tests`.

### الفحص الذاتي
أثناء البناء يُشغَّل البرنامج المبني تلقائياً بالأمر `SmartAuth.exe --selftest` ويتحقق من: قاعدة البيانات، وجود Tesseract وملفات العربية والإنجليزية داخل البرنامج، قراءة OCR فعلية، مكتبات PDF، محرك التوقيعات، Excel، النسخ الاحتياطي، وبناء كل صفحات الواجهة لنوعي الحساب. إذا فشل أي فحص يتوقف البناء ولا يُنتج ملف تثبيت معيب. يمكن تشغيل الأمر نفسه على أي جهاز بعد التثبيت للتأكد من سلامته.

### بيانات تجريبية
لتجربة المنظومة قبل إدخال بياناتكم (على نسخة تجريبية فقط):
```bat
python tools\seed_demo.py --user admin --password <كلمة المرور>
```
يضيف 6 جهات و8 أشخاص بتفويضاتهم وتوقيعات اصطناعية، وينشئ المجلد `demo_documents\signatures_to_scan` بصور توقيع "ممسوحة" لتجربة البحث بالتوقيع عبر زر (اختيار صورة من الجهاز).

## 4. مطابقة التوقيعات — كيف تعمل وحدودها

- المعالجة: إزالة الخلفية غير المنتظمة والتشويش، فصل الحبر، حذف نقاط الماسح، تحديد منطقة التوقيع وقصها، توحيد الحجم.
- الخصائص: HOG (اتجاهات الخطوط) + LBP (الملمس) + كثافة 128 منطقة + الإسقاطات الأفقية والعمودية + خصائص شكلية؛ تُحسب مرة واحدة عند الأرشفة وتُخزن في قاعدة البيانات، فيكون البحث سريعاً حتى مع آلاف التوقيعات.
- إعادة ترتيب أفضل النتائج بمطابقة نقاط ORB مع تحقق هندسي (RANSAC).
- على عينة اختبار اصطناعية (توقيعات مع ميلان ±6°، تغيير الحجم، سُمك القلم، تشويش الماسح): التوقيع الصحيح في المرتبة الأولى في نحو 87–97% من الحالات، بمتوسط تشابه ~87% للتوقيع نفسه مقابل ~10–18% لتوقيعات أشخاص آخرين.
- **مهم:** هذه أرقام على بيانات اصطناعية. يجب معايرة حد التشابه (الافتراضي 55%) على توقيعات حقيقية من أرشيفكم. النسبة مؤشر بصري مساعد **ولا تثبت أصالة التوقيع أو صحة نسبته قانونياً** — هذا التنبيه يظهر دائماً في الشاشة.

## 5. الكتابة اليدوية — ما يجب معرفته

- النصوص **المطبوعة** العربية والإنجليزية: Tesseract (مع ملفات `tessdata_best`)، وقد تم اختبارها.
- الكتابة **اليدوية الإنجليزية**: نموذج `microsoft/trocr-base-handwritten` المعروف، يُنزّل عند البناء ويعمل محلياً.
- الكتابة **اليدوية العربية**: لا يوجد نموذج مفتوح المصدر واحد معتمد بدقة عالية لكل الخطوط. البرنامج جاهز لتحميل أي نموذج TrOCR عربي (بصيغة HuggingFace) من المجلد `models\handwriting\ara`. أنصح بتجربة نموذجين أو ثلاثة على عينات من مستنداتكم الفعلية قبل الاعتماد، أو تدريب نموذج على عينات أرشيفكم.
- في كل الأحوال، المناطق التي لا يستطيع البرنامج قراءتها تظهر كتنبيهات بموضعها، وكل البيانات تمر بشاشة المراجعة قبل اعتمادها.

## 6. ما تم اختباره وما يلزم اختباره على Windows

تم في بيئة الاختبار (Linux) تشغيل 16 اختباراً آلياً ونجحت كلها، وتُضاف إليها 3 اختبارات للواجهة الحقيقية تعمل تلقائياً أثناء البناء على Windows:
- الدخول، قفل الحساب، منع إنشاء حساب أولي ثانٍ، حماية آخر مشغل رئيسي.
- منع المستخدم العادي في طبقة الخدمات **وفي قاعدة البيانات مباشرة** (INSERT/UPDATE/DELETE/DROP، وإخفاء كلمات المرور).
- التصنيفات والجهات والدول، البحث بالاسم مع اختلاف الهمزات، البحث بالهاتف بثلاث صيغ.
- حالة التفويض وانتهاؤه التلقائي.
- استيراد مجلد بمجلداته الفرعية مع اكتشاف الملف المكرر، OCR عربي وإنجليزي، PDF نصي، PDF ممسوح، تنبيه المستند الفارغ، اقتراح منطقة التوقيع، الاعتماد.
- البحث بالتوقيع (الترتيب، تضييق النطاق، عدم العثور، عدم تسجيل صورة البحث، عدم تعديل الأصول).
- Excel (أوراق متعددة، تعديل، حفظ بنسخة سابقة، استيراد الأشخاص).
- النسخ الاحتياطي والاستعادة.
- بناء كل صفحات الواجهة لنوعي الحساب وربطها بالخدمات (اختبار دخان دون Qt حقيقي).

**يلزم اختباره يدوياً على جهاز Windows فعلي**: مظهر الواجهة واستخدامها، الماسح الضوئي عبر WIA/TWAIN مع جهازكم، نموذج الكتابة اليدوية، وملف التثبيت. شغّل `installer\build.bat` (يشغّل الاختبارات تلقائياً قبل البناء) ثم جرّب سيناريو كاملاً: إضافة مسار ← قراءة ← مراجعة ← اعتماد ← بحث بالتوقيع الممسوح.

## 7. ملاحظة على ملف المتطلبات

ملف المتطلبات المرسل ينتهي في منتصف البند الخامس عند عبارة «يجب دعم تحسين جودة المستند قبل القراءة، بما...». تم تنفيذ كل ما ورد قبل ذلك، وتحسين الجودة قبل القراءة منفذ (إزالة التشويش، توحيد الإضاءة، تصحيح الميل، التكبير). أي بنود لاحقة لم تصل.
